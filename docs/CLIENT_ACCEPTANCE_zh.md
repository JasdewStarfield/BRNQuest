# BRNQuest 1.21.1 NeoForge 客户端验收

这份清单用于需要真实窗口、分辨率和人工观察的验证。每次测试请使用本批代码重新启动客户端，避免旧 JVM 继续加载修复前的 class。

## 1. 选择验收数据

日常 UI、进度和奖励测试优先使用 [`TEST_PACK_zh.md`](TEST_PACK_zh.md) 中的原生验收任务包。它不依赖整合包内容，覆盖矩阵稳定且正常加载应为零诊断。

只有验证 FTB Quests 格式 13 导入时，才准备 EOW 导入源：

在 `1.21.1-neoforge` 目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\validation\prepare-eow-fixture.ps1
```

预期输出为 `Prepared 9 verified EOW fixture files`。脚本只复制测试 fixture，不修改仓库中的源文件。

## 2. 主菜单与语言

1. 启动 `runClient`，进入主菜单。
2. 打开 Mods，选择 BRNQuest。
3. 确认版本 `0.1.0-alpha.1`、作者和 MIT 许可证正常显示。
4. 将语言切换为简体中文，确认菜单可正常刷新，无缺字方框和崩溃。

## 3. 导入、重载与网络回归

本批新增了描述字段和作者顺序语义。请创建一个允许作弊的新世界，避免旧世界中上一版生成的数据包遮蔽新导入结果，然后依次执行。旧数据包的任务 JSON 不含 `subtitle`/`description` 字段，`/reload` 不会重建它，导入命令也按安全策略拒绝覆盖，所以不能复用旧世界验证描述。

```text
/brnquest workspace import_ftb eow embers_of_winter main --dry-run
/brnquest workspace import_ftb eow embers_of_winter main
/brnquest workspace deploy
/brnquest workspace reload
/brnquest validate
/brnquest open
```

预期结果：

- dry-run 和实际导入都报告 `6 chapters, 53 quests`；仅安装 BRNQuest 的开发环境应为 `0 errors, 6 warnings`，这些 warning 对应未安装的 Farmer's Delight 物品和 FTB 缺失物品占位符；
- 第二次 workspace 导入拒绝覆盖已有作者工作区；同一世界第二次普通 deploy 拒绝覆盖已有部署；
- validate 报告 `53 quests` 和一个 64 位十六进制 revision；
- `/brnquest open` 不得再出现 `String too big`、`EncoderException` 或断线；
- 任务书显示 6 个章节，节点可以选择，拖动画布与滚轮缩放有效；
- 按 `J` 可快速打开任务书，并可在“控制”设置中重新绑定；任务界面黑色背景覆盖整个屏幕，不再保留外圈空隙；
- 详情栏和章节栏均可滚动到最后一个条目完整可见；锁定任务的“未解锁”带提示标记，悬浮后显示依赖任务的章节和名称；
- 左侧章节栏可通过边缘把手展开/收回；状态行星标可以追踪任务，追踪后节点显示青色外圈且游戏 HUD 显示目标状态；
- 逐个点击未完成的目标行进行确认/提交，逐个点击奖励物品领取；悬浮物品目标和物品奖励应显示原版物品 Tooltip；详情栏不再显示底部大按钮；
- 左栏按“流程设计”“冬日余烬”两个章节组显示；“冬日余烬”下依次为总集章、序章、C1、C1.5、C2；
- 初次开屏不显示详情栏，任务画布使用右侧空间；点击节点后详情以覆盖式抽屉打开，可用右上角 `×` 或 `Esc` 收起；
- 原版世界背景保持模糊，但章节文字、任务节点和详情文字清晰；
- 显式任务图标优先；未显式设置图标时使用首个目标的物品、勾选或自定义占位符，不使用奖励作为默认图标；
- 依赖线按实际节点坐标转折，并在被依赖任务一端显示方向箭头；
- 缩放时节点边框、图标、连线和箭头同步缩放；被画布或详情抽屉遮挡的物品图标不得穿透到前景；
- 鼠标位于左栏时滚轮滚动章节，位于详情抽屉时滚动详情；两个区域内容溢出时均显示滚动条，最末项目可以完整显示；
- 鼠标位于画布时滚轮缩放，以当前可视画布中心为锚点，缩放范围限制在 50%-200%；
- 缺失模组物品或未知类型保留节点，并使用安全占位显示。

## 4. UI 与进度回归

分别在 1280×720 和 1920×1080 窗口执行：

1. 逐个切换章节，检查章节组、章节栏、画布、右侧详情区不重叠或越界。
2. 分别打开含描述、物品目标和 checkmark 目标的任务，确认标题、副标题、详细描述、目标名称和当前/所需数量可读。
3. 在物品不足和物品充足时分别打开同一个物品任务，确认“可完成”提示和完成按钮状态随条件变化。
4. 选择可用 checkmark 任务并完成，确认状态更新且依赖任务随即解锁。
5. 追踪一个可用任务，确认 HUD 能显示追踪目标；再次点击取消追踪。
6. 获得某个 item 任务要求的物品，确认观察型任务自动完成。
7. 确认任务完成前没有领取按钮；完成一个多奖励任务后确认全部奖励图标可见，点击单项图标和“领取全部可用奖励”都可领取，且每项只能发放一次。
8. 背包填满后领取物品奖励，确认剩余物品安全掉落在玩家位置。
9. 退出并重新进入世界，确认完成、追踪和领取状态保持。
