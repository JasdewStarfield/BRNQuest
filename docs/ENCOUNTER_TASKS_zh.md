# 观察与击杀目标

观察使用 `brnquest:observe`，击杀使用 `brnquest:kill_entity`。编辑器提供中英文类型、字段与服务端 ID / 原生标签选择器，列表沿用分页和平滑滚动。图标只作展示，不带物品 tooltip 或 JEI 快捷键。

## 观察

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `kind` | `block` 方块或 `entity` 实体 | `block` |
| `target` | 对应注册表 ID 或 `#namespace:tag` | `minecraft:dirt` |
| `distance` | 最大观察距离，有限数且大于 0、不超过 64 格 | `8` |
| `duration` | 连续观察 tick 数，整数 0–1200；20 tick 通常为一秒 | `0` |
| `title` | 可选自定义标题 | 类型与目标名称 |

例如 `kind=block`、`target=#minecraft:logs`、`duration=40` 要求连续观察同一个原木方块约两秒。`duration=0` 表示首次有效命中即可完成。

服务端使用玩家眼部位置与朝向检查最近的可命中对象。方块与实体都可遮挡，超出距离、移开视线或切换到另一个对象会重新计时；不主动加载区块，射线范围存在未加载区块时暂不判定。流体不作为观察目标。实体必须可以被射线选中。

连续计时属于玩家本人，不叠加队友的观察时间；只有完整观察后才写入共享进度。断线、维度切换、数据重载、配置变化或显式重置会清理相应临时计时。完成后离开目标不倒退；重置后需要重新观察。客户端计时仅供显示，最终完成由服务端决定。先追踪该任务，再关闭任务界面；右上角追踪 HUD 会显示实时 tick 计时。击杀未达到总量时同样显示实际计数，不显示绿色完成。

## 击杀

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `target` | 实体类型 ID 或 `#namespace:tag` | `minecraft:zombie` |
| `count` | 所需击杀数，正整数，最大为 Java long 上限 | `1` |
| `title` | 可选自定义标题 | 类型与目标名称 |

只计算目标可推进期间的新击杀：玩家直接造成的致命伤害，或归属于该玩家的投射物造成的致命伤害。宠物、纯环境伤害、被取消的死亡与旧击杀不计入。击杀一个实体只记一次；队伍模式写入一次共享账本，不按在线成员重复增加。已完成目标不继续累加，依赖与顺序目标遵守现有规则；计数随进度存档保存。

## FTB 导入

`observation` 转为观察目标，`timer` 转为 `duration`；`observation_type` 的 `block` / `block_tag` / `entity_type` / `entity_type_tag` 转为目标种类及 ID/标签。旧字段 `observe_type` 存在时按 FTB 的优先级读取，并在冲突时提示。FTB 没有对应最大距离字段，转换默认使用 8 格。BRNQuest 的计时以服务端 tick 为准。

`kill` 转为击杀目标；`entityTypeTag` 优先于 `entity`，`value` 转为 `count`，省略时沿用 FTB 默认值 100。标签会规范为 `#namespace:tag`。

方块状态、方块实体、方块实体类型、实体自定义名称和 NBT 筛选无法在此阶段等价转换。导入会保留源字段，报告错误并写入 `ftb.encounter_error`，阻止该目标以更宽松条件启用。作者确认替代语义后再修改配置并移除此标记。

## 扩展与兼容

类型通过任务与客户端 presentation 注册表接入，字段来源复用 `ServerFieldSources`，完成及计数复用现有进度 API。`QuestScreen` 不判断观察或击杀类型；引擎只新增通用临时状态重置回调，供任意扩展目标复用。

当前公共 API 为 experimental.12、网络协议为 15。客户端与服务端须同步更新。运行时不依赖 FTB Quests。

目标行的省略号可打开全部解析成员，优先显示方块/实体名称。tooltip 只列前三项与省略号，完整列表支持平滑滚动和搜索。
