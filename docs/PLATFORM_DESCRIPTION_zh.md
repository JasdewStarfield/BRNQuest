# BRNQuest

**带有游戏内可视化编辑器的 Minecraft 任务系统，为整合包、冒险地图和多人服务器组织玩法进程。**

用章节串联探索与成长，用任务引导玩家掌握新机制，再用奖励和剧情回应他们的进展。BRNQuest 将任务编排、内容编辑和进度追踪集中在一本任务书中。

## 你可以用它做什么？

- 为整合包制作新手教程、科技路线和阶段目标。
- 为冒险地图安排探索、收集、战斗与剧情任务。
- 为多人服务器设置共享目标、全员挑战和可重复活动。
- 配合 BRNTalk，把对话阅读、剧情完成和后续对话接入任务流程。

## 功能亮点

### 在游戏内编排任务

使用可视化画布创建章节、摆放任务并连接依赖关系。编辑器支持多选、拖动、复制粘贴、章节复制、撤销和重做；任务书与章节的创建默认值可减少重复配置。

普通编辑保存后即时生效。高级草稿提供独立编辑、版本保存、差异审阅与发布流程，适合持续迭代整合包内容。

### 用多种目标组织玩法

任务可以要求玩家持有或提交物品、合成指定物品、获得经验、进入维度或群系、发现结构、到达指定区域、观察方块或实体、击杀目标，以及完成原版进度。手动确认目标适合教程与阅读提示。

结合前置依赖、顺序目标、可选目标、隐藏条件、重复周期与冷却，可以组织从入门引导到长期挑战的任务线。

### 配置奖励与奖励表

提供物品、经验、命令、原版进度和原生战利品表等奖励。奖励表支持组合发放、随机抽取和玩家自选，也可以嵌套引用其他奖励表。

### 按整合包风格展示内容

任务描述支持 Markdown v1，可使用标题、列表、强调、链接和图片。任务图标、画布装饰与背景可引用资源包贴图；内置多语言编辑帮助作者为同一本任务书提供不同语言的内容。

玩家可以将任务追踪到 HUD，通过物品选择界面提交目标，并在奖励选择界面确认自己的选择。

### 为队伍设计进度

联动 Open Parties and Claims 后，可共享队伍进度，也可要求每位队员分别完成目标。奖励可以按成员领取，或由整队领取一次。任务书可选择使用个人进度或队伍进度。

### 导入与扩展

支持导入 FTB Quests v13 的受支持内容。导入结果保存为草稿，并生成转换报告，便于检查和调整后发布。

KubeJS 服务端脚本和 Java API 可用于查询进度、处理事件、推进任务及扩展目标与奖励类型。

## 可选联动

| 模组 | 用途 |
| --- | --- |
| **JEI** | 查询物品配方与用途，配合物品选择器，并避让物品栏任务按钮 |
| **Open Parties and Claims** | 队伍身份、共享进度与成员奖励 |
| **KubeJS + Rhino** | 服务端脚本、任务事件与自定义类型 |
| **BRNTalk** | 消息已读和对话完成目标，以及开始对话、继续对话和打开对话界面奖励 |

## 快速开始

1. 准备 **Minecraft 1.21.1、NeoForge 21.1 和 Java 21**，在服务端与所有客户端安装相同版本的 BRNQuest。单人游戏直接安装到客户端。
2. 进入世界，按 **J**，或点击物品栏左上角的任务图标打开任务书。
3. 使用拥有 **权限等级 2** 的账号进入编辑模式，创建章节、任务、目标和奖励。
4. 整合包作者可随整合包分发任务工作区，并通过资源包提供贴图。具体编辑、部署与恢复步骤见[作者指引](https://github.com/JasdewStarfield/BRNQuest/blob/mc%2F1.21.1-neoforge/docs/AUTHOR_GUIDE_zh.md)。

## 快速转换当前 FTB 任务

使用 **BRNQuest 1.0.1 或更新版本**，先在 FTB Quests 中保存任务书，再用拥有 **权限等级 2** 的账号执行：

```text
/brnquest import_ftb_local
```

命令直接读取当前实例的 `config/ftbquests/quests/`，将受支持的 FTB Quests v13 任务内容转换为 BRNQuest 的 `ftbquests:main` 草稿，包含章节、语言和奖励表，无需手动复制文件。多人游戏读取服务端的文件。

按 **J** 打开任务书，进入编辑器的**高级草稿目录**，打开导入的任务书。根据聊天提示和 `config/brnquest/reports/` 中的报告检查转换结果，调整后**发布并应用到当前世界**。

如需先预览转换结果，可执行 `/brnquest import_ftb_local --dry-run`，只生成诊断报告。已有同名草稿时不会覆盖；再次导入可使用新名称，例如 `/brnquest import_ftb_local mypack retry`。

转换保留 FTB 源文件，仅导入任务定义，不迁移玩家或队伍进度。自定义图片仍需保留对应资源包。详细支持范围见[导入说明](https://github.com/JasdewStarfield/BRNQuest/blob/mc%2F1.21.1-neoforge/docs/CONTENT_REFERENCE_zh.md#ftb-导入)。

## AI 与开发者职责

BRNQuest 由开发者主导设计与维护，使用 AI 工具参与开发。

- **开发者**：负责功能设计、架构决策、美术素材、实际游戏测试与验收、版本发布和持续维护，决定实现方案与最终采用的内容。
- **AI**：根据开发者的需求与反馈生成和修改代码，协助重构、问题分析、自动化验证与文档编写。
