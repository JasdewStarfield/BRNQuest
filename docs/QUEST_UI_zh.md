# 任务界面与编辑操作

任务书使用灰石面板、类型图标和状态角标。章节导航、任务画布和右侧详情保留各自位置；小窗口可收起侧栏，为画布留出空间。

## 玩家

1. 选择章节和任务，在右侧查看条件、进度与奖励。长列表可滚动，截断名称可悬停查看；跟踪 HUD 使用同一目标名称与进度。
2. 物品提交窗口显示计划扣除数量。选择背包格后确认，服务器再次检查物品；取消不提交。等待响应时不要重复点击，超时后可手动重试。
3. 自选奖励先选中候选，再按确认。退出后可从奖励入口继续当前选择；奖励表预览只用于查看，不会抽取或领取。随机候选不代表本次确定产物。
4. 物品保留原生名称、组件 Tooltip 和数量。安装 JEI 时，真实物品可查询配方；装饰类型图标不作为物品查询。经验点数与等级分开显示。

## 作者

章节右键菜单可打开属性，修改名称、物品/贴图图标及分组。章节 ID 只读。编辑模式拖动章节可排序或跨组移动，Esc 或在列表外松手取消；组标题可折叠，折叠状态按任务书记忆到本次游戏退出。

基础属性和目标/奖励配置仍在侧栏；必填字段、可选字段与完成/领取规则分区显示。选择器返回保留父表单输入。奖励表可编辑子表与叶子，路径提示当前层级。

注意本地表单与两种编辑模式的区别：

- 子窗口“应用到上层”只修改父表单；父层取消仍会丢弃这些本地改动。
- 普通“编辑任务书”使用实时编辑：完成表单并被服务器接受后，写入当前世界并立即生效。依据状态栏确认结果，本地改动和等待不能当作已保存。
- “高级草稿”保持独立草稿：保存后仍需审阅并确认发布。游戏内发布流程依次发布、部署并重载，全部成功后才应用到运行中的任务书。审阅显示名称、图标和字段前后值，“…”可查看完整诊断。发生版本冲突时重新审阅，不重复发布旧预览；失败时按具体阶段提示恢复。

## 输入

选择器支持 Tab 焦点导航、方向键浏览和 Enter 激活。自选奖励的选中与确认是两个动作。物品候选编辑使用 F6 切换候选/背包区域；提交窗口使用 F6 切换按钮/背包，空格选择格子。Esc 返回或取消当前层。键盘导航期间隐藏鼠标 Tooltip，移动鼠标后恢复。

更多内容：[工作区与恢复](WORKSPACE_zh.md)、[奖励表](REWARD_TABLES_zh.md)、[扩展展示接口](EXTENSION_API_zh.md)。

右上角齿轮打开 BRNQuest 客户端设置，包括网格吸附、滚动、动画速度和自动居中。浏览与编辑模式均可使用，不要求作者权限。原生设置页在返回时保存修改，无需重启即可生效；NeoForge 默认文件监听开启时，也会热重载外部修改的 `brnquest-client.toml`。已经开始的拖动保持开始时的吸附策略。

两种编辑模式下，顶栏左侧的网格图标可直接切换吸附：高亮表示开启，斜线表示关闭，Tooltip 仅显示当前状态。个人偏好不会修改任务书 revision 或撤销记录。

右键章节组标题，打开**章节组属性**，可修改名称、选择或清空物品/贴图图标、填写简短说明。确认后应用，取消保留原值。导航标题旁显示组图标，悬停显示说明；修改属性或重排不会丢失未知扩展数据。

章节组名称按当前游戏语言编辑，其他语言译文保留；图标与简短说明为共享元数据。仅调整图标或说明不会生成新的名称译文。

组名、章节名及任务标题／副标题快捷编辑中的语言按钮默认选中玩家当前语言。点击可选择已有语言，或输入新语言代码（如 `ja_jp`）后编辑译文，无需切换游戏语言。回退来源仅在按钮 Tooltip 中简短显示；切换语言保留当前表单的输入，确认统一保存所有改动，取消全部丢弃。单字段快捷编辑不会改动其它文本字段。

当前语言没有译文时，回退文本仅显示为灰色占位参考；输入从空白开始，未输入就确认不会创建译文。编辑默认语言本身时，原生默认文本仍可直接编辑。

编辑模式中，画布右键 → 任务书属性可编辑书标题、默认语言和新任务默认值；章节属性提供该章的默认值入口。模板支持形状、大小、图标缩放、最小宽度，以及依赖可见/完成前隐藏、可开始前隐藏详情、完成前隐藏说明、顺序目标和可重复。数字留空、开关选“默认”使用上层值；明确关闭和 0 不代表未设置。合并顺序为核心 → 书 → 章 → 本次覆盖，只影响新建任务；修改模板不改变已有任务，复制和移动保留任务现有值。模板子窗口确认后仍需确认外层属性窗口，外层取消会丢弃改动。

新任务默认值还支持：完成前隐藏任务、显示所需完成目标数、隐藏锁图标、依赖判定方式、重复冷却秒数和忽略奖励阻塞。阈值与冷却只接受非负整数；明确填写 0 会覆盖上层值，留空则使用上层默认。依赖方式可选择全部/任一依赖完成或已开始。

### 新建项默认值与任务书设置

任务书属性中的“创建默认值与书设置”可设置新物品目标默认消耗、新奖励默认团队共享及领取方式，也可抑制全书自动领取和开启单人任务界面暂停。章节属性可覆盖物品消耗默认值，选择“默认”恢复书继承。创建默认值不修改已有项，复制保留源项配置；需要玩家选择的奖励默认手动领取。

抑制自动领取对已有奖励立即生效，并让原本隐藏的自动奖励可见、可手动领取；关闭抑制后恢复原自动策略，已领取奖励不会重复发放。暂停适用于单人任务界面的浏览、普通编辑和高级草稿模式；多人游戏不暂停。

章节属性中的“自动聚焦”可搜索并选择本章节任务，或选择“无”。打开该章节或重新打开任务界面时，目标居中于可见画布，缩放保持不变；子窗口返回不重复定位，也不打开任务详情。改名同步引用，删除或移出目标清空引用，撤销可恢复。原生章节 JSON 使用可选 `autofocus_id`（命名空间任务 ID）；FTB 同名字段中的十六进制任务引用在导入时转换，非任务／跨章节／失效引用仅保留并报告警告。

编辑模式下也可右键任务节点，选择“设为章节自动聚焦”；该操作可撤销，重复设置同一目标不会生成变更。未配置目标时提示“未设置自动聚焦任务”。
