# 任务界面与编辑操作

任务书使用灰石面板、类型图标和状态角标。章节导航、任务画布和右侧详情保留各自位置；小窗口可收起侧栏，为画布留出空间。

## 玩家

1. 选择章节和任务，在右侧查看条件、进度与奖励。长列表可滚动，截断名称可悬停查看；跟踪 HUD 使用同一目标名称与进度。
2. 物品提交窗口显示计划扣除数量。选择背包格后确认，服务器再次检查物品；取消不提交。等待响应时不要重复点击，超时后可手动重试。
3. 自选奖励先选中候选，再按确认。退出后可从奖励入口继续当前选择；奖励表预览只用于查看，不会抽取或领取。随机候选不代表本次确定产物。
4. 物品保留原生名称、组件 Tooltip 和数量。安装 JEI 时，真实物品可查询配方；装饰类型图标不作为物品查询。经验点数与等级分开显示。

## 作者

章节右键菜单可打开属性，修改名称、物品/贴图图标及分组。章节 ID 只读。编辑模式拖动章节可排序或跨组移动，Esc 或在列表外松手取消；组标题可折叠，折叠状态按任务书记忆到本次游戏退出。

基础属性和目标/奖励配置仍在侧栏；必填字段、可选字段与完成/领取规则分区显示。选择器返回保留父表单输入。奖励表可编辑子表与叶子，路径提示当前层级。

注意本地表单与两种编辑模式的区别：

- 子窗口“应用到上层”只修改父表单；父层取消仍会丢弃这些本地改动。
- 普通“编辑任务书”使用实时编辑：完成表单并被服务器接受后，写入当前世界并立即生效。依据状态栏确认结果，本地改动和等待不能当作已保存。
- “高级草稿”保持独立草稿：保存后仍需审阅并确认发布。游戏内发布流程依次发布、部署并重载，全部成功后才应用到运行中的任务书。审阅显示名称、图标和字段前后值，“…”可查看完整诊断。发生版本冲突时重新审阅，不重复发布旧预览；失败时按具体阶段提示恢复。

## 输入

选择器支持 Tab 焦点导航、方向键浏览和 Enter 激活。自选奖励的选中与确认是两个动作。物品候选编辑使用 F6 切换候选/背包区域；提交窗口使用 F6 切换按钮/背包，空格选择格子。Esc 返回或取消当前层。键盘导航期间隐藏鼠标 Tooltip，移动鼠标后恢复。

更多内容：[工作区与恢复](WORKSPACE_zh.md)、[奖励表](REWARD_TABLES_zh.md)、[扩展展示接口](EXTENSION_API_zh.md)。

右上角齿轮打开 BRNQuest 客户端设置，包括网格吸附、滚动、动画速度和自动居中。浏览与编辑模式均可使用，不要求作者权限。原生设置页在返回时保存修改，无需重启即可生效；NeoForge 默认文件监听开启时，也会热重载外部修改的 `brnquest-client.toml`。已经开始的拖动保持开始时的吸附策略。

两种编辑模式下，顶栏左侧的网格图标可直接切换吸附：高亮表示开启，斜线表示关闭，Tooltip 仅显示当前状态。个人偏好不会修改任务书 revision 或撤销记录。

右键章节组标题，打开**章节组属性**，可修改名称、选择或清空物品/贴图图标、填写简短说明。确认后应用，取消保留原值。导航标题旁显示组图标，悬停显示说明；修改属性或重排不会丢失未知扩展数据。

章节组名称按当前游戏语言编辑，其他语言译文保留；图标与简短说明为共享元数据。仅调整图标或说明不会生成新的名称译文。

组名、章节名及任务标题／副标题快捷编辑中的语言按钮默认选中玩家当前语言。点击可选择已有语言，或输入新语言代码（如 `ja_jp`）后编辑译文，无需切换游戏语言。回退来源仅在按钮 Tooltip 中简短显示；切换语言保留当前表单的输入，确认统一保存所有改动，取消全部丢弃。单字段快捷编辑不会改动其它文本字段。

当前语言没有译文时，回退文本仅显示为灰色占位参考；输入从空白开始，未输入就确认不会创建译文。编辑默认语言本身时，原生默认文本仍可直接编辑。

编辑模式中，画布右键 → 任务书属性可编辑书标题、默认语言和新任务默认值；章节属性提供该章的默认值入口。模板支持形状、大小、图标缩放、最小宽度，以及依赖可见/完成前隐藏、可开始前隐藏详情、完成前隐藏说明、顺序目标和可重复。数字留空、开关选“默认”使用上层值；明确关闭和 0 不代表未设置。合并顺序为核心 → 书 → 章 → 本次覆盖，只影响新建任务；修改模板不改变已有任务，复制和移动保留任务现有值。模板子窗口确认后仍需确认外层属性窗口，外层取消会丢弃改动。

新任务默认值还支持：完成前隐藏任务、显示所需完成目标数、隐藏锁图标、依赖判定方式、重复冷却秒数和忽略奖励阻塞。阈值与冷却只接受非负整数；明确填写 0 会覆盖上层值，留空则使用上层默认。依赖方式可选择全部/任一依赖完成或已开始。

### 新建项默认值与任务书设置

任务书属性中的“创建默认值与书设置”可设置新物品目标默认消耗、新奖励默认团队共享及领取方式，也可抑制全书自动领取和开启单人任务界面暂停。章节属性可覆盖物品消耗默认值，选择“默认”恢复书继承。创建默认值不修改已有项，复制保留源项配置；需要玩家选择的奖励默认手动领取。

抑制自动领取对已有奖励立即生效，并让原本隐藏的自动奖励可见、可手动领取；关闭抑制后恢复原自动策略，已领取奖励不会重复发放。暂停适用于单人任务界面的浏览、普通编辑和高级草稿模式；多人游戏不暂停。

章节属性中的“自动聚焦”可搜索并选择本章节任务，或选择“无”。打开该章节或重新打开任务界面时，目标居中于可见画布，缩放保持不变；子窗口返回不重复定位，也不打开任务详情。改名同步引用，删除或移出目标清空引用，撤销可恢复。原生章节 JSON 使用可选 `autofocus_id`（命名空间任务 ID）；FTB 同名字段中的十六进制任务引用在导入时转换，非任务／跨章节／失效引用仅保留并报告警告。

编辑模式下也可右键任务节点，选择“设为章节自动聚焦”；该操作可撤销，重复设置同一目标不会生成变更。未配置目标时提示“未设置自动聚焦任务”。

编辑模式下，目标/奖励条目菜单可“复制配置”，在同书另一任务的对应列表点击“粘贴”。列表焦点支持 Ctrl+C/V；文本编辑仍复制粘贴文字。剪贴板保存复制时的配置，源项随后修改或删除不影响它；每次粘贴生成新 ID 并可独立撤销。未知私有引用原样保留。首版限当前游戏进程、同服务器/世界及同任务书，配置快照上限 64 KiB。

复制任务时，为已有各语言的标题添加副本标记（中文“（副本）”，其他语言“(Copy)”），同名冲突使用统一递增编号。缺失或空翻译继续原有回退；副标题、正文和扩展文本不变。复制副本不会堆叠标记。

按住 Ctrl 点击任务节点或装饰贴图可加入／移出同一选区；Ctrl 点击以及多选状态下的点击不会打开任务详情或自动聚焦。长按任一已选的未锁定对象可整体移动，保持相对位置，并使用当前网格吸附设置。多选后，右键已选对象或画布空白处会打开独立菜单，可整体复制、整体删除或取消选择。复制统一向右下偏移一个网格单位，保留内部相对位置；内部依赖重映射到新任务，外部依赖与私有配置引用原样保留。任务、目标、奖励均分配全新 ID，已有语言标题采用副本编号。删除需确认，并移除其他任务指向所删任务的依赖；复制和删除均只占一个撤销步骤。右键未选节点仍按单任务操作。

编辑模式下，在章节右键菜单选择“复制章节”，副本会放在同组原章节之后。整章任务、目标、奖励使用独立 ID，坐标和章节配置保留；内部依赖与自动聚焦指向副本任务，跨章依赖及未知配置引用原样保留。章节和任务的已有标题翻译添加副本编号，缺失翻译保持回退。支持空章节和一次撤销／重做，不复制玩家进度。

单个或多个任务／装饰右键选择“复制到剪贴板”，切换到同任务书的目标章节，在画布目标位置右键选择“粘贴画布对象”。集合最小 X／Y 位置对齐粘贴点，保留相对布局。复制时的任务配置与多语言文本会被冻结；后来修改或删除源任务不影响粘贴。内部依赖指向副本，外部依赖保持；外部任务已删除则拒绝整次粘贴并提示。粘贴保留显式属性，不套用目标章节创建默认值或修改其自动聚焦，支持重复粘贴及一次撤销／重做。剪贴板限同一世界／服务器和任务书，每次快照最多64 KiB，超限提示且保留原剪贴板。

任务详情状态行右端并排显示两个无常驻边框的 16×16 双箭头 PNG 图标，分别打开前置／后续任务弹窗，不另占一行。无对应任务时图标淡化但仍可点击。列表较长时可滚动，无对应任务时显示空列表；条目显示任务标题、章节和状态，点击可跨章跳转聚焦。浏览模式继续遵循隐藏任务／文本规则，高级草稿显示预览状态。

章节属性 →“新建任务默认值”中的“隐藏依赖线”控制章节默认显示策略；任务属性 →“编辑行为”中的“隐藏依赖线”可选“继承章节／隐藏／显示”。设置控制指向该任务的入向连线，不改变依赖判定。聚焦任务时，相关前置／后续线仍分别以蓝色／橙色高亮。缺省章节值为关闭，缺省任务值为继承；复制任务保留其显式值，继承项在目标章节按目标默认值显示。

客户端设置还提供：打开详情时自动收起目录、滚轮缩放步长、网格显示（始终／仅编辑／不显示）、节点长按时间、减少动画、编辑模式与浏览位置记忆、目录及详情栏自定义宽度。宽度 0 使用自动布局，自定义宽度受窗口限制以保留画布空间。设置支持即时生效；长按时间从下次按下生效，记忆开关从下次打开生效。界面记忆仅保留在当前游戏进程内。

### 画布装饰与背景

有编辑权限时，右键画布选择“添加装饰贴图”，选定贴图后立即在本次右键位置创建，取消选择不创建。右键装饰贴图本身，选择“装饰贴图属性”，可独立设置这张贴图的资源、坐标、宽高、等比缩放、层级和锁定。左栏按当前宽高比例预览贴图，右栏编辑属性。等比缩放开启时，修改宽度或高度会立即联动另一项；关闭后可分别编辑。小窗口中可在右栏滚动。点击“应用”将本次表单修改作为一次可撤销编辑提交，取消丢弃本次表单修改。

“浏览已加载贴图”列出当前资源包提供的 PNG，可按资源名称过滤并预览。任务和章节图标均可点击当前贴图预览打开此浏览器，空值显示添加按钮，取消选择保留原值。资源 ID 使用 `命名空间:textures/路径.png`；资源缺失时显示紫色占位，保留引用，恢复资源包并重新加载后即可恢复。图片来自客户端资源包或本地素材库，任务书只保存资源 ID；其他玩家也需要本机具备对应素材。

装饰在右键位置创建，并遵循网格吸附设置。坐标与宽高使用任务网格单位。应用后，在主画布左键拖动装饰可移动；拖动右下角金色方块可缩放。网格吸附同时用于预览和落点；等比缩放保持当前宽高比。锁定阻止画布拖动、缩放和 Delete 删除，仍可在属性窗口解锁或管理。装饰层级从小到大绘制，同层按稳定 ID 排序，所有装饰位于任务节点下面。浏览模式中装饰不接收输入。

主画布选中装饰后 Ctrl+C 复制，Ctrl+V 粘贴到当前可见画布中心。连续粘贴生成独立 ID；重叠时优先选中最上层装饰，可移开后操作下方贴图。剪贴板限当前游戏进程、同服务器/世界和同任务书。文本框聚焦时 Ctrl+C/V 仍编辑文字。整章复制也复制装饰并生成新 ID。复制不包含玩家进度、目标或奖励领取状态。

“画布背景”和“界面背景”各自支持平铺、完整适配、填充裁剪以及 0–1 的透明度数值（0 为全透明，1 为不透明）。画布背景跟随画布移动和缩放；完整适配/填充的基准为原点居中的 1024×1024 画布像素区域。界面背景固定在屏幕空间，按当前窗口适配。背景页提供原始比例的独立贴图预览和 0.25–8 倍缩放设置（旧配置默认 1 倍）。倍率调整平铺单元大小，或在完整适配/填充的结果上居中缩放。平铺默认使用 128×128 像素单元；画布平铺随缩放变化。面板与模态窗口保持在背景上方。

章节属性和任务书属性均通过“背景设置”进入统一编辑页，在页内切换画布/界面编辑目标；切换不提交，应用与取消共同处理两种背景。左下角固定层级按钮在“继承/默认”“画布背景在上”“界面背景在上”间切换，不随编辑目标或右侧滚动变化。章节继承任务书顺序，未配置时默认画布背景在上；顺序只影响两个背景，装饰与任务节点始终在其上方。按钮提示与背景属性页标明两者区别。背景属性页临时隐藏章节栏、任务详情栏和上下工具栏，让画布预览覆盖全窗口；退出后保留原侧栏状态。背景属性页使用半透明面板，在后方实时预览资源、适配方式、透明度及继承/禁用效果，预览不改变草稿；任务书属性直接预览书级默认值，不受当前章节覆盖影响。数字或资源 ID 尚未输入完整时保留上一有效预览。切换到“自定义”不会自动打开选择器，需点击“浏览已加载贴图”；切换模式会保留当前输入。子页“应用”仅更新外层属性的待保存内容，外层“完成”才一起提交；取消外层属性会丢弃背景修改。“继承 / 重置”恢复任务书设置，“禁用”明确关闭该章对应背景。书级重置恢复无自定义背景。每章最多 128 个装饰，尺寸每边为 0.05–1024 网格单位，坐标范围 ±1,000,000，层级范围 ±10,000；完整场景配置受 64 KiB 字符长度限制。背景不支持远程 URL；本机 PNG 可通过选择器导入，素材文件不上传。


### 导入本地素材

在贴图选择器中点击“导入本地 PNG”，选择图片，或将单张 PNG 拖入选择器。导入完成会定位到对应资源；点击条目才会用于当前图标、装饰或背景。取消文件选择不导入，取消外层属性不保存任务书修改；已导入的素材仍保留在本地素材库。

支持静态 PNG（含透明通道），文件最多 8 MiB，每边最多 4096 像素。导入时验证并规范化图片，再按内容分配稳定的 `brnquest_local:textures/imported/<hash>.png` 地址；相同素材重复导入复用地址。原始文件保持不变，移动或删除原文件不影响已导入素材。

素材保存在当前游戏目录的 `brnquest/local-assets/assets/brnquest_local/textures/imported/`，由模组自动加载，无需手工制作或启用资源包。重启或重新加载资源后仍可使用。任务书保存、上传及发布只包含 resource location，不包含图片字节或本机路径；本阶段不提供素材分发，其他客户端没有对应素材时显示缺失占位。备份或迁移本地素材时，需单独保留该素材目录。

任务节点和装饰贴图共用 Ctrl+C／Ctrl+V 剪贴板，粘贴点为可见画布中心；右键粘贴使用右键位置。混合移动、复制、粘贴和删除均可一次撤销／重做。锁定贴图可以选中和复制，整体移动或删除时跳过它；选中单个未锁定贴图时才显示右下缩放手柄，多选拖动不改变尺寸。


### 编辑提交后的即时显示

提交移动、缩放、属性、增删或复制粘贴后，编辑界面会立即保留改动后的画面，等待服务端确认时不再闪回旧状态。完整回包验证成功后静默接入服务端结果；若服务端拒绝，则恢复原数据与选区并显示错误。分块同步期间也保留待确认画面。

待确认结果只用于编辑界面显示，不会成为已保存草稿、已发布任务书或玩家进度；游戏交互仍遵循已确认的服务端状态。等待时保持现有的单次提交限制。撤销／重做可即时显示本次会话缓存的已确认历史；客户端没有对应历史时仍等待服务端结果。退出会话、断线或切换任务书不会沿用旧预览。
