# 任务界面与编辑操作

任务书使用灰石面板、类型图标和状态角标。章节导航、任务画布和右侧详情保留各自位置；小窗口可收起侧栏，为画布留出空间。

## 玩家

1. 选择章节和任务，在右侧查看条件、进度与奖励。长列表可滚动，截断名称可悬停查看；跟踪 HUD 使用同一目标名称与进度。
2. 物品提交窗口显示计划扣除数量。选择背包格后确认，服务器再次检查物品；取消不提交。等待响应时不要重复点击，超时后可手动重试。
3. 自选奖励先选中候选，再按确认。退出后可从奖励入口继续当前选择；奖励表预览只用于查看，不会抽取或领取。随机候选不代表本次确定产物。
4. 物品保留原生名称、组件 Tooltip 和数量。安装 JEI 时，真实物品可查询配方；装饰类型图标不作为物品查询。经验点数与等级分开显示。

## 作者

章节右键菜单可打开属性，修改名称、物品/贴图图标及分组。章节 ID 只读。编辑模式拖动章节可排序或跨组移动，Esc 或在列表外松手取消；组标题可折叠，折叠状态按任务书记忆到本次游戏退出。

基础属性和目标/奖励配置仍在侧栏；必填字段、可选字段与完成/领取规则分区显示。选择器返回保留父表单输入。奖励表可编辑子表与叶子，路径提示当前层级。

注意本地表单与两种编辑模式的区别：

- 子窗口“应用到上层”只修改父表单；父层取消仍会丢弃这些本地改动。
- 普通“编辑任务书”使用实时编辑：完成表单并被服务器接受后，写入当前世界并立即生效。依据状态栏确认结果，本地改动和等待不能当作已保存。
- “高级草稿”保持独立草稿：保存后仍需审阅并确认发布。游戏内发布流程依次发布、部署并重载，全部成功后才应用到运行中的任务书。审阅显示名称、图标和字段前后值，“…”可查看完整诊断。发生版本冲突时重新审阅，不重复发布旧预览；失败时按具体阶段提示恢复。

## 输入

选择器支持 Tab 焦点导航、方向键浏览和 Enter 激活。自选奖励的选中与确认是两个动作。物品候选编辑使用 F6 切换候选/背包区域；提交窗口使用 F6 切换按钮/背包，空格选择格子。Esc 返回或取消当前层。键盘导航期间隐藏鼠标 Tooltip，移动鼠标后恢复。

更多内容：[工作区与恢复](WORKSPACE_zh.md)、[奖励表](REWARD_TABLES_zh.md)、[扩展展示接口](EXTENSION_API_zh.md)。

右上角齿轮打开 BRNQuest 客户端设置，包括网格吸附、滚动、动画速度和自动居中。浏览与编辑模式均可使用，不要求作者权限。原生设置页在返回时保存修改，无需重启即可生效；NeoForge 默认文件监听开启时，也会热重载外部修改的 `brnquest-client.toml`。已经开始的拖动保持开始时的吸附策略。

两种编辑模式下，顶栏左侧的网格图标可直接切换吸附：高亮表示开启，斜线表示关闭，Tooltip 仅显示当前状态。个人偏好不会修改任务书 revision 或撤销记录。
