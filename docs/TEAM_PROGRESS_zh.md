# 队伍任务进度

任务书设置中的“共享队伍任务进度”默认开启。关闭后，处于同一个 OPAC 队伍的玩家使用各自的个人任务进度和奖励记录，OPAC 队伍关系保持不变。原生任务书字段为 `settings.share_team_progress`。

任务的行为设置中可开启“要求队内全员完成”（`behavior.require_all_team_members`，默认关闭）。在共享模式下，该任务的每项目标由每位成员分别完成，物品提交也分别扣除；成员完成后显示“个人目标已完成，等待队友完成”。全员完成前不会开放该任务奖励，也不会满足后续任务的“已完成”前置条件。普通任务继续共享目标计数。个人模式或未加入队伍时，此开关按普通个人任务处理。

完成前以当前 OPAC 队员名单判定，包含离线成员。新成员加入后需要完成自己的目标；退出成员不再阻塞完成。任务一旦完成，后续入队不会重新锁住它，新成员也不能领取此前完成周期的奖励。已完成前置在可重复任务的新周期中仍按现有规则有效。

个人记录与队伍记录分别保留。切换共享设置只切换使用的记录，不自动合并、复制或清空历史。全员目标记录属于具体队伍，退出再加入同一队伍可恢复本周期的记录；加入其他队伍不会带入这些记录。对已完成任务开启全员规则保留完成历史；若作者需要重新执行，应使用任务重置。

重置整个任务会清除该队伍所有成员在该任务内的目标记录与奖励领取记录。重置单个目标会清除全体成员的该目标并重新要求个人完成，保留已经领取的奖励。可重复任务的新周期清除全体成员的本周期目标记录。管理员强制完成整个任务可直接绕过全员条件；强制完成单个目标仅推进所选玩家的目标。
