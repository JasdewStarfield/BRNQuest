# Toolbar icons

Editable 16×16 RGBA GUI sprites: `settings.png`, `snap_on.png`, and `snap_off.png`.
Transparent padding preserves the compact toolbar silhouette; white pixels receive the button tint. The off variant includes a red diagonal mark. The shared renderer adds the shadow, so do not bake one into the PNG.

Edit these PNGs directly. Resource packs can override the same paths; F3+T reloads the GUI atlas. Java uses `brnquest:editor/toolbar/<name>` without a file extension.
