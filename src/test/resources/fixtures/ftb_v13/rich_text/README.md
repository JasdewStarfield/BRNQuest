# P4c pinned FTB rich-text fixture

This format-13 fixture locks the client-visible conversion baseline for legacy
format codes, raw JSON links, stable quest links, images, page breaks, and
independent English/Chinese descriptions. It is test-only and is not packaged
in the production mod JAR.

The source syntax follows FTB Quests `v2101.1.34` at commit
`02bd2f0efe68721d1e87cd5cc69d9d3d43798b85` and its matching FTB Library
`2101.1.35` parser.

## 简体中文

此格式 13 夹具固定旧格式码、原始 JSON 链接、稳定任务链接、图片、分页和独立中英文正文的客户端可见转换基线。它仅用于测试，不进入正式模组 JAR。

来源语法以 FTB Quests `v2101.1.34`、提交 `02bd2f0efe68721d1e87cd5cc69d9d3d43798b85` 及匹配的 FTB Library `2101.1.35` 解析器为准。
